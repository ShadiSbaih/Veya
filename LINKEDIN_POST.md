🚀 Excited to unveil **Veya** — Conversations That Produce Outcomes!

I've been working on Veya, a full-stack, cross-platform collaboration app that aims to transform how we chat, plan, and execute. Veya moves beyond standard messaging by turning chats into actionable spaces, decisions, and tasks—all in one place!

📱 **Available everywhere:** iOS, Android, and Web, powered by one unified codebase using **React Native & Expo**.

**Key Features:**
🔹 **Real-time Messaging:** 1-on-1 and group chats with typing indicators, presence, and read receipts, delivered instantly via **WebSockets**.
🔹 **Contextual Conversations:** Tag chats as a Plan, Event, Study, Project, or Decision to give structure and metadata to your discussions.
🔹 **Decisions:** Make choices easily with in-chat polls. Create options, cast votes, and finalize decisions seamlessly.
🔹 **Spaces & Tasks:** Turn a simple chat into a dedicated Space with a goal, deadline, and actionable tasks to keep everyone on track.
🔹 **Stories:** Share ephemeral moments via 24-hour image/video stories.

**The Tech Stack:**
*   **Frontend:** React Native 0.81, Expo Router v6 (file-based navigation), TypeScript
*   **Backend:** Node.js (ESM), Express 5, WebSocket (ws)
*   **Database:** MongoDB Atlas via Mongoose 9
*   **Authentication:** Clerk (lazy user sync for a flawless onboarding experience)
*   **Media Storage:** Cloudinary

I’m particularly proud of the architecture decisions, like the single shared HTTP + WS server, platform-aware media uploading, and in-memory participant caching to reduce database loads.
